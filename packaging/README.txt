mouselaser for Windows (experimental)
=====================================
Aim the SteamVR laser pointer with your mouse, including the SteamVR dashboard.

Install
  1. Unzip this folder somewhere permanent (SteamVR loads the driver from here,
     so do not move or delete it afterwards).
  2. Double-click install.bat.
  3. Restart SteamVR.
  4. Put on the headset and press your mouse's forward side button to toggle
     mouse laser mode. Press it again to give the mouse back to Windows.

Uninstall: double-click uninstall.bat, then restart SteamVR.

If something goes wrong: SteamVR Settings > Developer > Manage Add-ons, switch
mouselaser off. Logs: <Steam>\logs\vrserver.txt (lines starting with "mouselaser:").

This is experimental software. See the project README for details and settings:
https://github.com/Recour/frame-unboundedMouse-vibed
